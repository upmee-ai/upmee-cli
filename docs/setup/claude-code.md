# Claude Code setup

Open a terminal at the repository root and start Claude Code. The project skills are under `.claude/skills/`.

Make `UPMEE_API_KEY` available to that session. Run `/upmee_setup` to verify access to your team, then try `/upmee List the connected accounts for my team`. If the assistant cannot open the current English **List Accounts** reference, copy its Markdown from the UPMee Open Platform and provide it in the session.

The setup command keeps its existing name. Configure secrets outside the conversation.
