# Setup with other AI assistants

1. Open this repository as the working directory or add its relevant files as context.
2. Provide [setup instructions](../../skills/upmee-setup/SKILL.md) and [execution instructions](../../skills/upmee/SKILL.md). If the assistant supports Agent Skills, follow its installation steps for those directories.
3. Provide the [endpoint index](../api-index.md) and load the linked local reference for the operation you want to run.
4. Configure the API key in the local execution environment. Ask the assistant to list connected accounts as a first read-only task.

Assistants without local execution access can prepare a request for you to review and run. Discovering an operation and executing it are separate capabilities.
