# Codex setup

Open this repository as the project in Codex. The project skills are under `.agents/skills/`.

Make `UPMEE_API_KEY` available to the local execution environment. Invoke `$upmee-setup` to check team access, then try `$upmee List the connected accounts for my team`. Provide the current English **List Accounts** Markdown if Codex cannot access the reference.

For remote execution, configure secrets in that environment and verify that it can reach the API. Local files and environment variables may be unavailable there.
