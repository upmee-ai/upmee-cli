# Update a Shoppable Video Task (Shop)

### Request URL

`https://www.upmee.cc/open_api/shop/task/update`

### HTTP Method

`POST`

### Request Headers

<!-- api-fields -->

| Field | Required <!-- api-tag --> | Type | Description |
| --- | --- | --- | --- |
| API-Key | Required | string | API key |
| Content-Type | Required | string | Request content type.<br>Allowed format: `application/json`. |

### Request Parameters

<!-- api-fields -->

| Field | Required <!-- api-tag --> | Type | Description |
| --- | --- | --- | --- |
| task_id | Required | string | ID of the task to update. It must be a Shop video task belonging to the team identified by `team_id`. Only drafts or scheduled tasks that have not been published can be edited. Other states return “Only drafts or scheduled tasks can be edited before publication.” |
| team_id | Required | string | Team ID |
| media_ids | Required | []string | List of social account IDs |
| title | Required | string | Task title |
| video_id | Required | string | Video file ID |
| is_independence | Optional | number | Multi-platform settings mode. 0: shared basic information. 1: separate settings. Default: 0. |
| tiktok_shop_creator_data | Required | object | Data required to publish a video on TikTok Shop |
| tiktok_shop_creator_data.cover_id | Optional | string | Cover file ID |
| tiktok_shop_creator_data.desc | Optional | string | Description. Must be shorter than 3000 characters. |
| tiktok_shop_creator_data.product_title | Required | string | Product anchor title. Must be shorter than 30 characters. |
| tiktok_shop_creator_data.media_product | Required | map\<string, object\> | Product information stored per social account |
| tiktok_shop_creator_data.media_product.Key | Optional | string | Social account ID |
| tiktok_shop_creator_data.media_product.Value | Optional | object | Product information for one social account |
| tiktok_shop_creator_data.media_product.Value.id | Required | string | ID of the product selected for one social account |
| tiktok_shop_creator_data.is_ai_generated | Optional | bool | Whether to label the post as AI-generated content.<br>If enabled, the published post displays the **Creator labeled as AI\-generated** label, which cannot be changed after publication. The label indicates that the content was fully generated by AI or substantially edited with AI.<br>Allowed values:  `true`，`false`。<br>Default:  `false`。 |
| tiktok_shop_creator_data.is_track_enabled | Required | bool | Whether to select background music |
| tiktok_shop_creator_data.track_info | Conditionally required | object | Required when `is_track_enabled = true`. |
| tiktok_shop_creator_data.track_info.track_id | Required | string | Track ID |
| common_data | Optional | object | Shared data |
| common_data.desc | Optional | string | Description. Provide this field or desc in the account-specific data. If both are provided, the account-specific value takes precedence. |
| common_data.cover_id | Optional | string | Cover file ID. Provide this field or cover\_id in the account-specific data. If both are provided, the account-specific value takes precedence. |
| pub_time | Conditionally required | number | Scheduled publication time as a timestamp in milliseconds. If omitted, the default is to publish immediately. If provided, it must be in the future. |
| is_draft | Optional | bool | Whether to save as a draft. Defaults to false. |

### Request Example

```json
{
    "task_id": "xxxxxx",
    "team_id": "xxxxxx",
    "media_ids": [
        "xxxxxx"
    ],
    "is_independence": 0,
    "title": "xxxxxx",
    "video_id": "xxxxxx",
    "common_data": {
        "desc": "xxxxxx",
        "cover_id": "xxxxxx"
    },
    "tiktok_shop_creator_data": {
        "cover_id": "xxxxxx",
        "desc": "xxxxxx",
        "product_title": "xxxxxx",
        "is_track_enabled": false,
        "track_info": {
            "track_id": "xxxxxx"
        },
        "is_ai_generated": false,
        "media_product": {
            "xxxxxx": {
                "id": "xxxxxx"
            }
        }
    },
    "is_draft": true
}
```

### Response Parameters

<!-- api-fields -->

| Field | Type | Description |
| --- | --- | --- |
| code | int | `0` indicates success |
| message | string | Status message |
| request_id | string | Unique request ID |
| data | object | Response data |
| data.task_id | string | Task ID |

### Response Example

```json
{
    "code": 0,
    "message": "OK",
    "request_id": "xxxxxx",
    "data": {
        "task_id": "xxxxxx"
    }
}
```
