# List Publishing Tasks (Shop)

### Request URL

`https://www.upmee.cc/open_api/shop/task/list`

### HTTP Method

`POST`

### Request Headers

<!-- api-fields -->

| Field | Required <!-- api-tag --> | Type | Description |
| --- | --- | --- | --- |
| API-Key | Required | string | API key |
| Content-Type | Required | string | Request content type.<br>Allowed format: `application/json`. |

### Request Parameters

<!-- api-fields -->

| Field | Type | Description |
| --- | --- | --- |
| page | number | Page number. Default: 1. Minimum: 1. |
| page_size | number | Page size. Default: 10. Range: 1–50. |
| team_id | number | Team ID |
| task_ids | string[] | List of task IDs. Up to 20 per request. |
| pub_time_filter | number | Publication time range filter：<br>- `-1`: No filter<br>- `7`: Videos published in the last 7 days<br>- `30`: Videos published in the last 30 days<br>- `90`: Videos published in the last 90 days<br>- `365`: Videos published in the last 365 days |
| pub_video_filter | string | Publisher scope filter:<br>- `team`: Tasks published by the team<br>- `self`: Tasks published by the current user |

### Request Example

```json
{
    "team_id": "xxxxxx",
    "page": 1,
    "page_size": 1,
    "pub_time_filter": -1,
    "pub_video_filter": "team"
}
```

### Response Parameters

| Field | Type | Description |
| --- | --- | --- |
| list | object[] | Task list |
| list.task_id | string | Task ID |
| list.team_id | string | Team ID |
| list.state | string | Task status：<br>- `wait`: Pending publication<br>- `publishing`: Publishing<br>- `publish_success`: Published successfully<br>- `publish_fail`: Publication failed<br>- `draft`: Draft<br>- `part_publish_success`: Partially published<br>- `part_publish_fail`: Partial publication failure |
| list.audit_state | string | Review status：<br>- `none`: Review has not started<br>- `auditing`: Under review<br>- `part_success`: Partially approved<br>- `success`: Fully approved<br>- `part_fail`: Partially rejected<br>- `fail`: Fully rejected |
| list.task_type | string | Task type：<br>- `video`: Video<br>- `picture`: Image |
| list.pub_time | number | Publication timestamp in milliseconds |
| list.medias | object[] | List of subtasks by social account |
| list.medias.sub_task_id | string | Subtask ID |
| list.medias.media_id | string | Social account ID |
| list.medias.media_type | string | Platform type |
| list.medias.avatar | string | Social account avatar URL |
| list.medias.name | string | Social account name |
| list.medias.state | string | Subtask status：<br>- `auditing`: Under review<br>- `part_success`: Partially succeeded<br>- `success`: Succeeded<br>- `part_fail`: Partially failed<br>- `fail`: All failed |
| list.medias.reason | string | Client error message |
| list.medias.error_msg | string | Error message |

| list.medias.item_id | string | Video ID |
| list.medias.cover | string | Cover URL |
| list.medias.video | string | Video URL on the external platform |
| list.medias.has_permission | bool | Whether access to the social account is authorized |

| list.cover | string | Cover URL |
| list.cover_id | string | Cover ID |
| list.video | string | Video URL |
| list.video_id | string | Video ID |

| list.tiktok_shop_creator_data.cover_id | string | Cover file ID |

| list.tiktok_shop_creator_data.is_track_enabled | bool | Whether to select background music |
| list.tiktok_shop_creator_data.track_info | object | Track information |
| list.tiktok_shop_creator_data.track_info.track_id | string | Track ID |
| list.tiktok_shop_creator_data.media_product | mapstring, object\> | Product information for this social account |
| list.tiktok_shop_creator_data.media_product.Key | string | Social account ID |
| list.tiktok_shop_creator_data.media_product.Value | object | Product information |
| list.tiktok_shop_creator_data.media_product.Value.id | string | Product ID |
| list.create_time | number | Task creation timestamp in milliseconds |
| page | number | Page number |
| page_size | number | Items per page |
| total_size | number | Total items |
| total_page | number | Total pages |
