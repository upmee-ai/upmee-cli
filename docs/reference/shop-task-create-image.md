# Create a Shoppable Photo Post Task (Shop)

### Request URL

`https://www.upmee.cc/open_api/shop/task/create/image`

### HTTP Method

`POST`

### Request Headers

<!-- api-fields -->

| Field | Required <!-- api-tag --> | Type | Description |
| --- | --- | --- | --- |
| API-Key | Required | string | API key |
| Content-Type | Required | string | Request content type.<br>Allowed format: `application/json`. |

### Request Parameters

<!-- api-fields -->

| Field | Type | Description |
| --- | --- | --- |
| team_id | string | Team ID |
| media_ids | []string | IDs of the social accounts selected for publishing |
| title | string | Task title |
| is_independence | number | Multi-platform settings mode. 0: shared basic information. 1: separate settings. |
| img_text_list | []object | List of images |
| img_text_list.key | string | Image file ID |
| tiktok_shop_creator_data | object | TikTok Shop creator task data |
| tiktok_shop_creator_data.desc | string | Description |
| tiktok_shop_creator_data.product_title | string | Product title. Up to 30 characters. |
| tiktok_shop_creator_data.is_ai_generated | bool | Whether to label the post as AI-generated content.<br>If enabled, the published post displays the **Creator labeled as AI\-generated** label, which cannot be changed after publication. The label indicates that the content was fully generated by AI or substantially edited with AI.<br>Allowed values:  `true`，`false`。<br>Default:  `false`。 |
| tiktok_shop_creator_data.is_track_enabled | bool | Whether to select music |
| tiktok_shop_creator_data.track_info | object | Required when `is_track_enabled=true`. |
| tiktok_shop_creator_data.track_info.track_id | string | Track ID |
| tiktok_shop_creator_data.media_product | mapstring,object\> | Product information stored per social account |
| tiktok_shop_creator_data.media_product.Key | string | Social account ID |
| tiktok_shop_creator_data.media_product.Value | object | Product information for one social account |
| tiktok_shop_creator_data.media_product.Value.id | string | ID of the product selected for one social account |
| common_data | object | Shared data used when there is no account-specific override |
| common_data.desc | string | Description. Provide this field or `desc` in the account-specific data. If both are provided, the account-specific value takes precedence. |
| common_data.cover_id | string | Cover file ID. Provide this field or `cover_id` in the account-specific data. If both are provided, the account-specific value takes precedence. |
| pub_time | number | Scheduled publication time as a timestamp in milliseconds. If omitted, the default is to publish immediately. If provided, it must be in the future. |
| is_draft | bool | Whether to save as a draft |
