# Update a Shoppable Photo Post Task (Shop)

### Request URL

`https://www.upmee.cc/open_api/shop/task/update/image`

### HTTP Method

`POST`

### Request Headers

<!-- api-fields -->

| Field | Required <!-- api-tag --> | Type | Description |
| --- | --- | --- | --- |
| API-Key | Required | string | API key |
| Content-Type | Required | string | Request content type.<br>Allowed format: `application/json`. |

### Request Parameters

<!-- api-fields -->

| Field | Required <!-- api-tag --> | Type | Description |
| --- | --- | --- | --- |
| task_id | Required | string | ID of the task to update. It must be a Shop photo post task belonging to the team identified by `team_id`. Only drafts or scheduled tasks that have not been published can be edited. Other states return “Only drafts or scheduled tasks can be edited before publication.” |
| team_id | Required | string | Team ID |
| media_ids | Required | []string | IDs of the social accounts selected for publishing |
| title | Required | string | Task title |
| is_independence | Optional | number | Multi-platform settings mode. 0: shared basic information. 1: separate settings. Default: 0. |
| img_text_list | Required | []object | List of images |
| img_text_list.key | Required | string | Image file ID |
| tiktok_shop_creator_data | Required | object | TikTok Shop creator task data |
| tiktok_shop_creator_data.desc | Required | string | Description |
| tiktok_shop_creator_data.product_title | Required | string | Product title. Up to 30 characters. |
| tiktok_shop_creator_data.is_ai_generated | Optional | bool | Whether to label the post as AI-generated content.<br>If enabled, the published post displays the **Creator labeled as AI\-generated** label, which cannot be changed after publication. The label indicates that the content was fully generated by AI or substantially edited with AI.<br>Allowed values:  `true`，`false`。<br>Default:  `false`。 |
| tiktok_shop_creator_data.is_track_enabled | Required | bool | Whether to select music. Defaults to false. |
| tiktok_shop_creator_data.track_info | Conditionally required | object | Required when `is_track_enabled=true`. |
| tiktok_shop_creator_data.track_info.track_id | Required | string | Track ID |
| tiktok_shop_creator_data.media_product | Required | map\<string, object\> | Product information stored per social account |
| tiktok_shop_creator_data.media_product.Key | Optional | string | Social account ID |
| tiktok_shop_creator_data.media_product.Value | Optional | object | Product information for one social account |
| tiktok_shop_creator_data.media_product.Value.id | Required | string | ID of the product selected for one social account |
| common_data | Optional | object | Shared data used when there is no account-specific override |
| common_data.desc | Conditionally required | string | Description. Provide this field or desc in the account-specific data. If both are provided, the account-specific value takes precedence. |
| common_data.cover_id | Conditionally required | string | Cover file ID. Provide this field or cover\_id in the account-specific data. If both are provided, the account-specific value takes precedence. |
| pub_time | Conditionally required | number | Scheduled publication time as a timestamp in milliseconds. If omitted, the default is to publish immediately. If provided, it must be in the future. |
| is_draft | Optional | bool | Whether to save as a draft. Defaults to false. |

### Response Parameters

<!-- api-fields -->

| Field | Type | Description |
| --- | --- | --- |
| code | int | `0` indicates success |
| message | string | Status message |
| request_id | string | Unique request ID |
| data | object | Response data |
| data.task_id | string | Task ID |
